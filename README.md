# 課堂冒險局

老師課堂用的答問管理工具：抽人作答、罰站、舉手抽道具卡、計分及匯出成績。

**直接用：** https://lphky.github.io/classroom-quiz/

## 介面

淺色應用程式風格：電腦用左側欄，手機用底部導航；按鈕一律用線條圖示（不用 emoji），按下有波紋及彈性回饋。四款道具做成有插畫、稀有度邊框及閃光的遊戲卡牌，滑鼠移上會立體傾斜。抽卡時翻牌揭曉；出卡時卡牌飛入發光並爆出粒子；抽人時名字滾動定格。設定可關閉動畫。卡牌插畫在 `assets/cards/`。

課堂另有 30 秒思考倒數、全班 10 題合作任務、搜尋與狀態篩選、專注投影及即時數據（不改分數）。首次開啟可一鍵建立 12 人虛構測試班，每人四種道具各一張。詳見 [五分鐘試玩](TRY-IT.md)。另備有可在設定還原的 [12 人測試備份](test-data/demo-backup.json)。

## 規則

- **冇人舉手** → 喺「出席又坐低」的同學入面按權重抽一位。答對 +1 分坐低；答錯去課室後面站立。
- **有人舉手** → 站立的同學排最前、優先作答。站立者答對可以坐返低（冇道具）。
- **坐低的同學主動舉手答對** → +2 分，再抽一張道具卡。答錯冇任何懲罰。
- 道具卡（背包上限 5 張，跨堂保留）：
  - 免答卡（稀有）：被抽中時用，即刻重抽另一位
  - 指定同學卡（史詩）：被抽中時指定一位坐低的同學代答（代答答錯由佢站）
  - 機率卡・調低（精良）：永久調低自己被抽中的機率
  - 機率卡・調高（傳說）：永久調高另一位同學被抽中的機率（要老師批准）
- 權重預設 100，每張卡 ±20，範圍 40–200；落堂後所有人自動坐返低。
- 分數、機率、上下限、背包上限、動畫等全部可以喺「設定」改。詳細規則見 [DESIGN.md](DESIGN.md)。

## 資料

所有資料只存喺該部機的瀏覽器（localStorage），唔會上傳。換機前喺「設定 → 下載備份」，新機「還原備份」。

## 開發

```bash
npm install
npx playwright install chromium
npm start        # http://127.0.0.1:4191/
npm test         # 規則單元測試 + 電腦/平板/手機瀏覽器測試
```

純 HTML + ES Modules，冇 framework、冇後端。規則邏輯喺 `js/logic.mjs`（純函數），畫面喺 `js/app.mjs`。
